> I have a serious problem with the word "default."
>
> My philosophy is rooted in the belief that the current system is merely the first draft. If a blueprint doesn't yet exist to solve a complex problem — I'll be busy designing it. If a system is in place, I'll be intensely focused on finding its faults and modifying and iterating new processes to fit in the best and most impactful way possible. *(p.s. — don't dismiss it saying "basically does whatever he wants")*

### Featured Projects

**Rotaract District 3011 Platform**

Production governance web platform and administrative portal serving 40+ member clubs across Delhi-NCR.

- Backend `rac3011-api`: NestJS 11, Prisma ORM 6, PostgreSQL, BullMQ, Redis, Better Auth with multi-tenant RBAC, PDF-lib document engine, Sentry, Pino.
- Frontend `rac3011-web`: React 18, Vite, Tailwind CSS, TanStack Query, Leaflet GIS district mapping, static prerendering, Playwright E2E testing.

**Culinary Partner** (`food-choose`)

AI-powered smart pantry and meal planner progressive web application. Google Gemini API for recipe recommendations, Supabase for real-time persistence, Framer Motion for fluid interactions.

**Financial Message Processor** (`forage-midas`)

Transaction ledger simulator based on J.P. Morgan Chase's engineering program. Java, Spring Boot, Maven, JUnit.
